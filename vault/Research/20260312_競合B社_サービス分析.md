# 競合B社 サービス分析

> Source: [Genspark](https://www.genspark.ai)

## 概要
A社商談に向けた競合B社のサービス分析。価格、機能、サポート体制を比較。

## 要点
- B社のエンタープライズプラン: 月額45万円（80ユーザーまで）
- API連携は基本的なREST APIのみ。GraphQLやWebhookは未対応。
- カスタマイズ性が低い。テンプレートベースのダッシュボードのみ。
- サポート: メールのみ、SLA保証なし。

## 当社との比較

| 項目 | 自社 | B社 |
|------|------|-----|
| 価格（100ユーザー） | 月額50万円 | 月額56万円（追加20ユーザー分） |
| API | REST + GraphQL + Webhook | REST のみ |
| カスタマイズ | フルカスタマイズ可 | テンプレートのみ |
| Salesforce連携 | 双方向同期 | 一方向のみ |
| サポート | 24/7 + 専任担当 | メールのみ |

## 所感・次のアクション
- 価格差は小さいが、技術面での優位性が明確。
- A社への提案時に、Salesforce連携とカスタマイズ性を強調すべき。
