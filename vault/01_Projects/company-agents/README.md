# 三国志エージェント経営システム

Claude Codeを活用した自律型エージェントチームによる会社経営支援システム。

## 概要

会社の各部署・役職を三国志の偉人にマッピングし、それぞれのキャラクター特性を
活かしたAIエージェントチームを構築する。

## 使い方

### 1. 特定のエージェントとして相談する

Claude Codeで以下のように指示：

```
曹操（CEO）として、来期の事業計画について意見を聞かせてください。
現在の売上は○○万円で、目標は○○万円です。
```

### 2. エージェント間の会議をシミュレーションする

```
経営会議をシミュレーションしてください。
議題：東京支店の売上低迷について
参加者：曹操（CEO）、諸葛亮（COO）、趙雲（東京営業）、周瑜（CMO）
```

### 3. タスクを割り振る

```
以下のタスクを適切なエージェントに割り振ってください：
- 来月の展示会の企画
- Q1の業績レビュー
- 新規採用3名の面接設計
```

### 4. 評価を実施する

```
諸葛亮（COO）として、呂布（静岡営業部長）のQ1評価を実施してください。
実績データ：契約数XX件、売上XXXX万円、成約率XX%
```

### 5. 戦略を議論する

```
曹操（CEO）と諸葛亮（COO）で、全国展開事業の3年計画について議論してください。
現在の加盟店数はXX店、目標はXX店です。
```

## 今後の拡張計画

### Phase 1: プロンプト運用（現在）
- 各エージェントのプロンプトを使い、手動で会話
- タスクや評価をMarkdownで管理

### Phase 2: Claude Code Hooks活用
- SessionStartで「朝会」を自動実行
- タスク完了時に自動で報告書生成
- 定期的な経営レポート自動生成

### Phase 3: MCP Server連携
- Slack連携で各エージェントがチャンネルに投稿
- Google Calendar連携で会議スケジュール管理
- CRM/会計システムとのデータ連携

### Phase 4: マルチエージェント自律運用
- Claude Agent SDKを活用した複数エージェントの自律連携
- エージェント間のメッセージングシステム
- 自動エスカレーション・承認フロー
