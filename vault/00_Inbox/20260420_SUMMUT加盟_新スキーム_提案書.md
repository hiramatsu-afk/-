# SUMMUT加盟プロジェクト 新スキーム提案書

## 1. 本提案の目的

認定工務店が存在しないエリアで「顧客が待っている」状況を解消し、
**紹介先行型** の新しい加盟スキームを導入することで、工務店・顧客・SUMMUT の三方よしを実現する。

## 2. スキーム変更のポイント

### Before（現行）
- **契約先行型**：まず加盟契約 → その後送客
- 工務店側は契約前に費用負担が発生

### After（新スキーム）
- **紹介先行型**：先にお客様を紹介 → 契約成立時点で初めて費用発生
- 工務店側は「契約になった案件分」だけ費用を負担すればよい
- 認定工務店不在エリアの見込み顧客にも即応可能

## 3. 新料金体系

### 契約成立時に発生する費用（契約時一括）

| 項目 | 金額 |
|------|------|
| **契約金** | **150万円** |
| **契約事務手数料** | **50万円** |
| **合計** | **200万円** |

> **契約が成立したタイミングで、初めて200万円を支払う形。**
> お客様が成約に至らなければ、工務店側の費用負担は発生しない。

### その他の条件（従来通り）

| 項目 | 金額 | 備考 |
|------|------|------|
| 月額費用 | 2万円 | 継続 |
| 年間更新料 | 10万円 | 継続 |

→ **ランニング条件は現行スキームを踏襲。初期費用の発生タイミングのみ変更。**

## 4. WB工法の扱い

### 4-1. WB工法 会員の場合
- **WB加盟料は不要**
- 新スキームの200万円のみで参画可能

### 4-2. WB工法 非会員の場合
以下の **いずれかの形式** を選択いただく。

#### オプション A：WB工法を追加契約し、自社で元請け
- WB工法 加盟契約を **100万円** で締結
- 工務店自身が元請けとして施工を担当
- 以降のWB工法案件も自社で完結可能

#### オプション B：平松建築が元請けとして施工を担当
- 今回の初回案件および今後の案件も、**平松建築が元請け** として施工を実施
- 工務店側は追加の加盟料を負担せずに参画可能
- 施工体制・品質は平松建築が担保

## 5. 費用発生フロー（新スキーム）

```
【認定工務店不在エリアで顧客が待機】
          │
          ▼
【SUMMUTが先に工務店へ紹介】  ← この時点では費用発生なし
          │
          ▼
【商談・提案】
          │
          ▼
【契約成立】  ←━━ ここで初めて費用発生
          │
          ├── 契約金 150万円
          ├── 契約事務手数料 50万円
          │   合計 200万円
          │
          ├─[WB会員]────── WB加盟料 不要
          │
          └─[WB非会員]
                ├── A. WB工法追加契約 100万円 → 自社で元請け
                └── B. 平松建築が元請けとして施工
```

## 6. スキーム比較サマリー

| 項目 | 現行スキーム | 新スキーム |
|------|-------------|-----------|
| 費用発生タイミング | 契約先行（加盟時） | 紹介先行（成約時） |
| 加盟金 | 150万円 | 150万円（契約金として） |
| 契約事務手数料 | 50万円 | 50万円 |
| 契約時合計 | ─ | **200万円** |
| 月額費用 | 2万円 | 2万円（同じ） |
| 年間更新料 | 10万円 | 10万円（同じ） |
| WB工法（会員） | ─ | 不要 |
| WB工法（非会員） | 100万円 | A: 100万円追加 / B: 平松建築が元請け |
| 認定不在エリアの対応 | 困難 | 即応可能 |

## 7. 導入メリット

### 工務店側
- **契約成立前の費用負担ゼロ**：リスクを抑えて参画可能
- **即案件着手**：認定不在エリアの顧客をすぐ対応できる
- **柔軟なWB工法対応**：会員／非会員、元請け体制を選択可

### 顧客側
- 待機時間の短縮、早期に施工可能な工務店とつながれる

### SUMMUT／平松建築側
- 空白エリアの機会損失を解消
- 非会員工務店にも「平松建築が元請け」という導入障壁の低い選択肢を提示可能
