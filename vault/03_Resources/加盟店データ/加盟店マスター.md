## ステータス定義
- **アクティブ**: 通常稼働中
- **要サポート**: 課題あり・サポート対応中
- **新規加盟**: 加盟後6ヶ月以内
- **開拓中**: 商談・検討中
- **休止**: 一時休止中
- **退会**: 退会済み

## データ投入方法

### 方法1: Google Driveスプレッドシートから同期
```bash
# 1. Google Drive認証（初回のみ）
python vault/scripts/gdrive_sync.py --setup

# 2. 加盟店管理スプレッドシートを同期
python vault/scripts/gdrive_sync.py --sync-file YOUR_SHEET_ID --dest "03_Resources/加盟店データ"
```

### 方法2: Claudeに直接データを渡す
「加盟店一覧のCSVデータを渡すので、このマスターデータに反映してください」
とClaude Codeに依頼すると、自動で整形して保存します。

### 方法3: 個別追加
新規加盟店が決まったら、Claudeに「○○工務店（東京都・代表△△）を加盟店マスターに追加して」と指示してください。

## 検索
```bash
# 特定の加盟店の全履歴（MTG・メール・メモ）を検索
python vault/scripts/business_hub.py --customer "工務店名"

# 加盟店関連ノートの一覧
python vault/scripts/business_hub.py --franchise-summary
```
